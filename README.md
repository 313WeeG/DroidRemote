Created by !ncogn!to. Works well with Kali-Linux & Termux.
Inspired by Android hacking tool "Pegasus"
ADB + scrcpy + Wireless Debug wrapper for android's wireless debugging function that allows you to pair your phone in kali OR termux terminal with a QR code. 
After successful connection run the scrcpy command to mirror target phone screen. 
(Note: Termux users.. Termux11 MUST be installed to export display..) You can find it here: https://github.com/313WeeG/termux-x11
ADB+scrcpy must be installed prior to first initialization of DroidRemote.
